NIOEE TEAM GIT RULES

1. Never push directly to main.
2. Make sure you work inside your branch.
3. Only work primarily inside your assigned files.
4. Do not modify another teammate’s files without informing the team please.
5. Pull the latest main before starting new work.
6. Make meaningful commits.
7. Open a Pull Request when your feature is ready.
8. Do not merge your own PR without team review.
9. Never commit API secrets, access tokens, refresh tokens, or .env files.
10. Test your feature before opening a PR.
